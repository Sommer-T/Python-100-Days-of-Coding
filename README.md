# Python 100 Days of Coding

This repository documents an earlier phase of my software engineering journey.

The project helped me strengthen my Python fundamentals, problem-solving skills, coding discipline, and confidence with project-based learning. While I no longer actively work through this curriculum, the experience contributed to my transition into building larger real-world projects such as Hero Academy, automation systems, and backend applications.

## Repository Status
