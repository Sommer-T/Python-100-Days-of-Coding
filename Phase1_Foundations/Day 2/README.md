# Day 2 - Tip Calculator 🧾

A simple Python tip calculator that splits the bill among multiple people.

## Features
- Accepts custom bill total
- Offers tip options: 10%, 12%, or 15%
- Splits total evenly across any number of people

## Usage
Run the script:
```bash
python task.py
```

## Sample Output
```
Welcome to the tip calculator!
What was the total bill? $80
What percentage tip would you like to give? 10, 12, or 15? 10
How many people to split the bill? 4
Each person should pay $22.00
```
