# Python 100 Days of Coding

A project-based Python learning journey based on Dr. Angela Yu’s 100 Days of Code bootcamp. This repository documents my growth from IT professional to software engineer through daily Python projects, notes, and reflections.

## Skills Practiced

- Python fundamentals
- Object-oriented programming
- File handling
- APIs and requests
- Flask web development
- Automation scripts
- Debugging and refactoring
- Git and GitHub workflow

## Project Categories

| Category | Examples |
|---|---|
| Beginner Python | games, conditionals, loops |
| Intermediate Python | OOP, files, error handling |
| APIs | requests, JSON, external data |
| Web Development | Flask, HTML, CSS |
| Automation | scripts and workflow tools |

## Learning Goal

My goal is not just to finish 100 days. My goal is to understand the concepts deeply enough to explain them, reuse them, and build original applications from them.
